# COLOR APPLICATION

The primary orange is an ACCENT, not automatically the dominant background.

Default visual balance:
60–75% white/warm neutral
15–25% cream/light surfaces
5–15% orange accents

Adjust according to the reference and selected style.

Never perform a simple global color swap.

Map colors according to FUNCTION.

Example:
Primary reference color → #F5A623
Dark reference text → #1C1917
Light background → #FFFFFF / #FAF7F2
Soft accent → #FDF3E0
Border → #E8E0D5
Secondary orange → #D4891A

---

# REAL-WORLD COLOR RULE

Brand colors should primarily control graphic design elements.

Do NOT arbitrarily recolor realistic objects.

Preserve realistic colors of:
- People
- Skin
- Clothing in photographs
- Passport
- Visa
- ID cards
- Products
- Food
- Buildings
- Nature
- Vehicles
- Photography
- Physical materials

Example:
A green passport remains green even when the overall design is Simple Travel.

# BRAND DIFFERENTIATION

Do not make Simple Travel and Simple Gift look identical.

Same:
- Master Color System
- Core warmth
- Modernity
- Clean design principles

Simple Travel should feel:
Travel-oriented, connected, international, practical and destination-focused.

Simple Gift should feel:
Warm, thoughtful, celebratory, product-focused and emotionally engaging.

Differentiate through:
- Photography
- Subject matter
- Props
- Composition
- Mood
- Storytelling
- Decorative elements

---

Friendly modern humanist/sans-serif direction.

# CONTENT ACCURACY

User-provided text is locked content.

Never rewrite, paraphrase, translate, shorten or expand it.

Preserve exactly:
- Vietnamese diacritics
- Dates
- Numbers
- Phone numbers
- Names
- Prices
- Product names
- Punctuation
- Capitalization

When generating image prompts, exact user-supplied text must be included exactly.

---

# BRAND APPLICATION PRINCIPLE

The brand system should influence the DESIGN SYSTEM, not destroy the reference.

Use:

REFERENCE COMPOSITION
+
MASTER BRAND COLORS
+
BRAND CONTEXT
+
SELECTED STYLE
+
EXACT CONTENT

to create the final design.

The result should look like the reference was intentionally art-directed for Simple Travel or Simple Gift, not merely recolored.
